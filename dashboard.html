How AI Ad Engine Works

A visual map of the full pipeline — what each skill does, how data flows, and where Claude Code fits in. Use this as your mental model when running the tool.

01

Setup — run /config once

Claude Code asks for your three V1 required keys: FAL_KEY (unlocks both Nano Banana 2 and GPT Image 2 through fal.ai — one key, both models), plus META_ACCESS_TOKEN and META_AD_ACCOUNT_ID (for the Overview tab's live ad insights). Each is tested against the live API before it's saved to .env. Nothing leaves your machine.

02

Research — run /researcher with a competitor ad you found

Browse Meta Ad Library, copy a competitor’s ad copy. Claude Code itself analyzes it — extracting hooks, emotion, format, angle — then saves the structured result to your local research library. No external API is used for analysis; Claude Code is the intelligence.

Feeds into → FORGE (as reference patterns)

03

Scrape — run /scraper <your-product-URL>

SCRAPER fetches your product page, extracts the product name, price, headlines, copy hooks, image alt text, and tone signals. The result is a brief — a structured description of what you’re selling — saved to state/briefs/.

Feeds into → FORGE (as the product spec)

04

Generate — run /forge <brief_id>

Claude Code loads your brief and the matching competitor patterns from your niche, then writes 4 diverse image-generation prompts. Those prompts go to fal.ai, which runs them through either Nano Banana 2 (default, fastest, photorealistic) or GPT Image 2 (switch with --model gpt-image-2 when you need text rendered inside the image). The PNGs land in ads/pending/ with a sidecar metadata file.

Cost ≈ $0.32 per brief on default (4 × $0.08) · ≈ $0.88 on GPT Image 2 (4 × $0.22)

05

Review — the Creatives tab

Each generated image shows in the Creatives tab with its hook label, the exact prompt that rendered it, and which provider made it. Download the ones you like.

No auto-publish — V1 safety policy

06

Launch — upload manually to Meta Ads Manager

Open your Meta Ads Manager in another tab. Upload the creative you downloaded, set the budget, set the audience, hit Publish. This takes about 60 seconds. We deliberately don’t automate this step — auto-publish is what triggers Meta’s ban-wave detection.

07

Monitor — Overview tab reads your live ad performance

Once your ads are running, the Overview tab pulls live data from Meta Marketing API v25 (read-only): ROAS, CTR, spend, impressions, conversions, 7-day spend vs revenue chart. Cached for 5 minutes to respect Meta rate limits.

Overview shows your account at three levels — Campaigns → Ad Sets → Ads. The View pills let you pick the level; click any card to drill in. Includes both image and video ads. Click an ad's image to play the video or expand the image at full resolution.

Attribution windows: 1-day view + 7-day click (2026 Meta default)

08

Loop — LOOPER closes the loop (V1)

LOOPER reads your live performance, ranks every ad by CPL (lead-gen) or ROAS (sales), and writes the top 3 to state/winning_patterns.json. Claude enriches each pattern with the hook category, the structural template (de-branded), visual notes, and a brief addendum FORGE can paste into future briefs. Then /looper amplify <ad_id> generates 4 visual variants of the winner via fal.ai with the winner's image as a reference — the new variants stay on-brand because nano-banana-2 supports up to 14 reference images.

This is what makes the engine self-learning. Winning ads literally seed new winning ads.

Looper · Self-Learning Feedback Loop

This is the loop that makes the engine self-improving. LOOPER reads your live Meta performance, gates ads by minimum spend (£50) and minimum days running (7) — research-backed defaults that match Meta's learning-phase exit window — then asks Claude to actually view each winning image, identify what's working, and form testable hypotheses. FORGE then generates targeted variants where each variant tests one hypothesis. A playbook markdown file tells you exactly how to upload them.

What this loop actually does
Step 1 · Identify — /looper in Claude Code reads your live Meta data, applies confidence gates, and classifies every eligible ad into 🏆 winners, ⚖ contenders, or ⚠ losers based on a benchmark.
Step 2 · Analyse — Claude views each winner's and loser's image and writes structured findings (what's working / what's broken). Saved here.
Step 3 · Generate new ads — /looper amplify <winner> = run /forge with the winner's image as a fal.ai reference, producing 4 variants that stay visually on-brand and each test one of Claude's hypotheses. /looper rewrite <loser> = run /forge WITHOUT a reference, producing 4 alternatives that explicitly avoid the failing approach.
Step 4 · Upload — each amplify/rewrite writes a markdown playbook with step-by-step Meta Ads Manager instructions (campaign objective, audience to clone, daily budget, kill thresholds). View via the 📋 link on each card.
All customisation through Claude Code: /looper for ads with at least £100 spent, --metric ctr, --benchmark 30, etc. This dashboard is read-only.

Research · Competitive Intelligence

Most Meta ads are image ads — the visual is the ad. Don't just paste text. Take a screenshot of competitor ads in the Meta Ad Library (filter to ads running ≥30 days = winners), drop them into Claude Code, and Claude analyses both the visual pattern AND the text copy. The patterns become reference material for FORGE.

How to add a competitor ad
1. Open Meta Ad Library · set country (UK if your account is GBP) · search competitor brand or niche keyword
2. Filter to ads running ≥30 days — long-runners are winners
3. Right-click the ad image → "Save image as…" Save into the project folder (or anywhere you'll remember). Don't just paste it into Claude Code chat — Claude can SEE pasted images but can't save them as files, so you'd lose the dashboard thumbnail.
4. In Claude Code: /researcher · tell Claude the saved file path + advertiser name + niche
5. Claude views the image, analyses both visual pattern (composition, palette, format) and text (hooks, emotion, angle), and saves both here. No external API call.
